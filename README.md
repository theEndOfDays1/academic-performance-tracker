# 📊 Academic Performance Tracker

A sophisticated, modular CGPA calculator designed for university students to track their academic progress across levels and semesters.

## 🛠 Tech Stack
- **Language:** HTML5, CSS3, JavaScript (ES6+ Modules)
- **Persistence:** LocalStorage API
- **Typography:** Sanchez & MiSans

## ✨ Key Features
- **Modular Architecture:** Logic and data are separated into ES6 modules for clean, maintainable code.
- **Auto-Persistence:** Your data is automatically saved to your browser; refresh and your grades are still there.
- **Dynamic Scaling:** Calculates GPA and Standing (1st Class, 2nd Class, etc.) in real-time.
- **Responsive Design:** Optimized for both mobile and desktop use.
